# 巷伴 動態標準字 v8：依設計稿三個關鍵姿勢（逐格向量）

打開 `index.html` 播放（純 SVG + JS，不需套件）。`rig.html` 是即時骨架版，用來調整動作與產生逐格輪廓。
預覽檔：`xiangban-light/dark.mp4`、`xiangban-light/dark.gif`（5 秒）、`xiangban-hands-closeup.gif`（雙手特寫）。

## 動作來源：設計者手繪的三張關鍵姿勢（`source/keyposes.jpg`）
1. **收起**：巷的手是縮小版（0.6 倍），接在屋頂斜邊末端；伴的撇整條往上滑、變短；拐杖獨自立著。
2. **伸手相握**：伴的撇滑出、手腕下彎；巷的手臂由短變長、手掌長回原尺寸，往上勾住伴的手。
3. **鬆開**：回到原本的標準字。

手掌位置、角度、縮放是用原稿手掌形狀去比對手稿量出來的（`fitkeys.py`、`fitx1.py` → `source/keys.json`），手臂姿態參數再用像素差異搜尋最吻合值。

## 概念：一次媒合，就是兩隻手在同一刻握到

| 專案理念 | 動態轉譯 |
|---|---|
| 長者不只是被照顧，而是還被需要 | **長者的手（伴，握拐杖）先伸出**，比青年早 0.25 秒起步 |
| 青銀雙向 | 青年的手（巷）慢一步回應，但兩隻手**同時抵達**，誰也不是單方面接受 |
| 即時完成的互助 | 握到時兩手**一起握緊一下**（過衝 1.8° 再回正），像一次確認 |
| 媒合者 | 不畫出來，而是那段「縮短距離」的過程本身；媒合者的工作就是讓兩手之間的空隙消失 |
| 社區的溫度 | 握手之後，家（巳）的窗燈才亮起：因為有這次互助，家裡亮了 |
| 長者的身體 | 拐杖完全不動，穩穩立著；長者的手伸下來握住它 |

## 時間軸（約 3.3 秒後靜止）

| 秒 | 動作 |
|---|---|
| 0–0.45 | 以姿勢 1 淡入 |
| 0.45 | 伴（長者）先起步：撇從頂端滑出、手腕下彎 |
| 0.55 | 巷（青年）起步：手臂從屋頂斜邊末端由短變長、手掌由小長大 |
| 1.6 | 兩手同時減速接觸（姿勢 2）；窗燈開始亮 |
| 1.5–2.2 | 握住：兩手以相同速度一起往上帶 5px 再落回（與抵達重疊，不停頓） |
| 2.2 / 2.28 | 鬆開：長者先放，青年晚 0.08 秒，結尾一點點回彈 |
| 3.0–3.3 | 原稿向量淡入蓋上，之後靜止 |

每隻手只走**一條幾何路徑＋一條速度曲線**（路徑以弧長均分），速度只有一個平滑波峰，中途不會煞停再加速。參數在 `gen6.py` 的 `M`：起步時間 `start`、接觸時間 `contact`、握住範圍 `clasp`、往上帶距離 `up`、鬆開時間 `rel`。

## 技術說明
**兩段式製作**
1. `rig.html`（由 `gen7.py` 產生）：骨架動畫。手臂每一格即時生成平滑輪廓，手掌保持原稿形狀，接在手臂末端。
2. `index.html`（由 `gen8.py` 產生）：逐格向量播放。**靜態筆畫永遠直接畫原稿向量**，逐格輪廓只包含移動的手和接縫附近，所以不動的邊緣不會每格重描而蠕動。把 `rig.html` 的手部區域以 3 倍解析度逐格渲染，只在「移動部分周圍約 3px」內做輕微平滑；手腕兩側的角與巷的肩膀這些接縫點周圍（`capture.js` 逐格記錄位置）用較強的平滑。再描回向量。靜態筆畫不受影響，播完淡回原稿。

**關鍵姿勢直接用設計稿**：0–0.45 秒兩隻手的輪廓就是設計稿第 1 張，0.45–0.75 秒用距離場漸變到骨架動畫；握住期間 1.6–2.2 秒用設計稿第 2 張（前後各 0.25 秒漸變），握住時往上帶的 5px 以局部變形套在手部，手臂根部不動。對位參數在 `source/key1reg.json`、`source/key2reg.json`。「巳」與屋頂三角形空洞不參與漸變，永遠用原稿。

**骨架細節**
- 巷的肩膀在屋頂斜邊上（x≈470），起點方向固定不轉，屋頂上緣不會出現缺口。下方是屋頂三角形空洞的那一側，寬度照空洞邊緣量；寬度依「離肩膀的實際距離」取樣，手臂再短也不會在下緣出現台階。
- 巷的手臂曲線從肩膀後方 60px 開始（藏在屋頂內），控制點採二次曲線等效，露出的部分盡量維持單純的 C 形。
- 巷的手腕繞肩膀後方的支點畫弧並伸長（極座標內插），手臂方向只會單向變化；手掌角度＝手臂方向＋手腕彎曲，手腕彎曲平均分散在整個伸手過程，不會和手臂反向扭轉。
- 收回時位置帶一點點回彈，角度不回彈。
- 巷的手從 0.6 倍長回原尺寸，手臂末端粗細跟著縮放；控制柄不超過手臂長度的 45%，短手臂不會扭成 Z 字。
- 伴的撇以頂端水平線為袖口，整條沿自身方向滑出，**撇保持筆直**，彎曲只集中在手腕前一小段；伸手時以手腕為軸微傾 3°。手掌相對手臂轉得越多，手臂末端的彎度就分散得越長（`bendK`），內側不會擠出折角。
- 拐杖（含握把）完全不動。「巳」以右緣 x≈524.5（實測）、上緣 y≈1079 為界整塊保留；手臂原稿與「巳」重疊 3px，靜止時沒有細縫。
- 屋頂三角形空洞：右邊緣到「巳」之間的三角區域固定為靜態，巷的移動部分以空洞為裁切範圍，空洞形狀在整段動畫中不變。
- 調整參數：`gen7.py` 的 `M`（時間），環境變數 `LIFT` / `DX` / `DY` / `LEAN`。`rig.html?debug` 會把手臂標綠、手掌標藍。

`frames-contact-sheet.png`：手部區域每 3 格一張的對照圖（標有格數與秒數），回饋時可直接指出格數。

## 放進網頁
把 `embed/xiangban-logo.js` 放到網站上，然後：
```html
<script src="xiangban-logo.js" defer></script>
<xiangban-logo trigger="load"></xiangban-logo>
```
- `trigger="load"`：開啟網頁就播放；不加則捲動到看得見時才播放。
- `delay="0.3"`：延遲秒數。`static`：不播放，直接顯示完成的標準字。
- 顏色用 CSS 變數：`--xiangban-ink`、`--xiangban-lamp-in`、`--xiangban-lamp-out`。
- `element.play()` 重新播放；播完會發出 `ended` 事件。
- 範例：`embed/example.html`。更新動畫後執行 `python3 gen_embed.py` 重新產生。

## 重新產生
```bash
pip install potracer scipy pillow numpy   # 另需 Node + Playwright
python3 build5.py            # 描出分層向量、量測手臂 → layers5.json
python3 gen7.py              # 骨架動畫 → rig.html
mkdir -p cap && node capture.js   # 逐格渲染手部區域 → cap/
python3 trace_frames.py 103  # 接縫平滑 + 描邊 → frames.json
python3 gen8.py              # 逐格向量播放 → index.html
```
（手稿更新時先跑 `fitkeys.py`、`fitx1.py` 重新量測關鍵姿勢。）

## 延伸到工具組
兩隻手的兩種姿態可以直接當成工具組的狀態符號：
- **張開**＝待媒合（需求卡、媒合板上還沒配對的狀態）
- **握到＋燈亮**＝這次互助完成（完成貼紙、App 回饋動畫、據點牆上的紀錄）

讓標準字的動態和工具的使用流程講同一件事。
