# 巷伴 動態標準字 v2

打開 `index.html` 播放（純 SVG + CSS）。`xiangban-light/dark.mp4`、`.gif` 為 6.5 秒預覽。

## 設計原則
- **演一次就停**：只有一段約 3.5 秒的進場，之後讓標準字靜止，只留窗燈極緩的呼吸。
- **用筆畫說故事**：遮罩加羽化邊緣，依筆畫方向浮現，不整塊移動，所以字距一直保持原樣。
- **牽手靠時間點**：巷的屋簷從屋頂往外展開，伴的撇從右上往下長，兩隻手在同一瞬間（約 1.4 秒）出現。
- **拐杖只落地一次**：杖身往下長出，著地時輕晃一下，衰減後停住。
- **燈只點亮窗格**：巳維持品牌色，窗格用奶油暖色漸層暖機式亮起，不閃爍、不加外光暈。
- **緩動**：expo-out 與 ease-in-out，不回彈。

## 時間軸
| 秒 | 動作 |
|---|---|
| 0.00 | 艹 由左往右顯影 |
| 0.25 | 半 由上往下；兩點 0.45 / 0.55 落下 |
| 0.45 | 屋簷與巳 從屋頂向外展開 |
| 0.65 | 人字撇 由上往下長到手 |
| ≈1.4 | 兩手同時出現 |
| 1.55 | 拐杖落下，1.85 起輕晃後靜止 |
| 2.40 | 窗燈暖機亮起，4.2 起緩慢呼吸 |

可調參數都在 `<style>`：`--lampIn / --lampOut`（燈色）、`@keyframes settle`（拐杖晃動）、`@keyframes idle`（呼吸，`.82` 改成 `1` 就完全靜止）。
