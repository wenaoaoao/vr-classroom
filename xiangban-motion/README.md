# 巷伴 動態標準字 v4：雙手伸出

打開 `index.html` 播放（純 SVG + CSS）。
預覽檔：`xiangban-light/dark.mp4`、`xiangban-light/dark.gif`（6.4 秒，完整畫面）、`xiangban-hands-closeup.gif`（雙手特寫）。

## 概念：一次媒合，就是兩隻手在同一刻握到

| 專案理念 | 動態轉譯 |
|---|---|
| 長者不只是被照顧，而是還被需要 | **長者的手（伴，握拐杖）先伸出**，比青年早 0.25 秒起步 |
| 青銀雙向 | 青年的手（巷）慢一步回應，但兩隻手**同時抵達**，誰也不是單方面接受 |
| 即時完成的互助 | 握到時兩手**一起握緊一下**（過衝 1.8° 再回正），像一次確認 |
| 媒合者 | 不畫出來，而是那段「縮短距離」的過程本身；媒合者的工作就是讓兩手之間的空隙消失 |
| 社區的溫度 | 握手之後，家（巳）的窗燈才亮起：因為有這次互助，家裡亮了 |
| 長者的身體 | 拐杖完全不動，穩穩立著；長者的手伸下來握住它 |

## 時間軸（4.4 秒後靜止）

| 秒 | 動作 |
|---|---|
| 0–0.5 | 標準字淡入。兩條手臂都是縮短的：伴的撇只有 22% 長，巷的手臂只有 12% 長、下垂 24° |
| 0.55 | 長者的手先伸出：撇由短伸長，向下掃到拐杖握把 |
| 0.85 | 青年的手從屋旁伸出，由短伸長並往上抬 |
| 2.05 | 兩手同時抵達 |
| 2.05–2.75 | 兩條手臂一起再伸 4.5% 後收回，像握住的那一下 |
| 2.35–3.75 | 窗燈暖機亮起，之後靜止 |

## 技術說明
- 手臂沿自身軸線伸縮（rotate · scaleX · rotate），筆畫粗細不變；手掌形狀不變，跟著手臂末端移動。
- 巷的手臂粗細一致（64px），肩膀放一個同寬的圓形關節，抬起時不會出現斷口。
- 拐杖（含握把）獨立成一層，完全不動。
- 關鍵影格由 `gen4.py` 的參數算出；要調整伸長比例、起始角度、時間，改 `arm_kf(...)` 的參數即可。

## 延伸到工具組
兩隻手的兩種姿態可以直接當成工具組的狀態符號：
- **張開**＝待媒合（需求卡、媒合板上還沒配對的狀態）
- **握到＋燈亮**＝這次互助完成（完成貼紙、App 回饋動畫、據點牆上的紀錄）

讓標準字的動態和工具的使用流程講同一件事。
