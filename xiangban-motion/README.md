# 巷伴 動態標準字 v6：依設計稿三個關鍵姿勢

打開 `index.html` 播放（純 SVG + JS，不需套件）。
預覽檔：`xiangban-light/dark.mp4`、`xiangban-light/dark.gif`（5 秒）、`xiangban-hands-closeup.gif`（雙手特寫）。

## 動作來源：設計者手繪的三張關鍵姿勢（`source/keyposes.jpg`）
1. **收起**：巷的手收在屋簷（肩膀）裡；伴的撇整條往上滑、變短；拐杖獨自立著。
2. **伸手相握**：伴的撇滑出、手腕下彎；巷的手從肩膀伸出並往上抬，兩手在拐杖握把旁勾在一起。
3. **鬆開**：回到原本的標準字。

手掌位置與角度是用原稿手掌形狀去比對手稿量出來的（`fitkeys.py` → `source/keys.json`）。

## 概念：一次媒合，就是兩隻手在同一刻握到

| 專案理念 | 動態轉譯 |
|---|---|
| 長者不只是被照顧，而是還被需要 | **長者的手（伴，握拐杖）先伸出**，比青年早 0.25 秒起步 |
| 青銀雙向 | 青年的手（巷）慢一步回應，但兩隻手**同時抵達**，誰也不是單方面接受 |
| 即時完成的互助 | 握到時兩手**一起握緊一下**（過衝 1.8° 再回正），像一次確認 |
| 媒合者 | 不畫出來，而是那段「縮短距離」的過程本身；媒合者的工作就是讓兩手之間的空隙消失 |
| 社區的溫度 | 握手之後，家（巳）的窗燈才亮起：因為有這次互助，家裡亮了 |
| 長者的身體 | 拐杖完全不動，穩穩立著；長者的手伸下來握住它 |

## 時間軸（約 3.4 秒後靜止）

| 秒 | 動作 |
|---|---|
| 0–0.45 | 以姿勢 1 淡入 |
| 0.45–1.7 | 伴的撇從頂端滑出，手腕下彎（長者先動） |
| 0.7–1.7 | 巷的手從肩膀伸出、往上抬，屋簷上緣跟著隆起 |
| 1.7–2.25 | 兩手相握（姿勢 2）；1.85 起窗燈亮起 |
| 2.25–3.1 | 鬆開，回到標準字（姿勢 3） |
| 3.1–3.4 | 原稿向量淡入蓋上，之後靜止 |

## 技術說明
- **手臂每一格即時生成**：從原字形量出中心線（貝茲曲線）與每個斷面的粗細，依手腕位置、手掌角度重畫平滑輪廓。手掌保持原稿形狀，接在手臂末端。
- **袖口裁切**：伴的撇以頂端水平線為袖口，整條沿自身方向滑出；巷的手從肩膀切線後方冒出。
- 巷抬手時，肩膀起點方向上揚，屋簷上緣用平滑曲線一起隆起，避免在肩膀折出硬角。
- 拐杖（含握把）完全不動；握把左半依手稿第 1 張補上。
- 抵達後換回原稿，靜止畫面與標準字一致。
- 調整：`gen6.py` 裡的 `T`（時間）、`KEY['lift']`（巷抬手角度）；網址加 `?debug` 會把手臂標綠、手掌標藍、屋簷隆起標橘。

## 重新產生
```bash
pip install potracer scipy pillow numpy
python3 build5.py   # 描出分層向量、量測手臂 → layers5.json
python3 fitkeys.py  # （手稿有更新時）重新量測關鍵姿勢 → source/keys.json
python3 gen6.py     # 產生 index.html
```

## 延伸到工具組
兩隻手的兩種姿態可以直接當成工具組的狀態符號：
- **張開**＝待媒合（需求卡、媒合板上還沒配對的狀態）
- **握到＋燈亮**＝這次互助完成（完成貼紙、App 回饋動畫、據點牆上的紀錄）

讓標準字的動態和工具的使用流程講同一件事。
