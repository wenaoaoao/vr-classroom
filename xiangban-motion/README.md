# 巷伴 動態標準字 v3：雙手

打開 `index.html` 播放（純 SVG + CSS）。
預覽檔：`xiangban-light/dark.mp4`、`xiangban-light/dark.gif`（6 秒）、`xiangban-hands-closeup.gif`（雙手特寫）。

## 概念：一次媒合，就是兩隻手在同一刻握到

| 專案理念 | 動態轉譯 |
|---|---|
| 長者不只是被照顧，而是還被需要 | **長者的手（伴，握拐杖）先伸出**，比青年早 0.25 秒起步 |
| 青銀雙向 | 青年的手（巷）慢一步回應，但兩隻手**同時抵達**，誰也不是單方面接受 |
| 即時完成的互助 | 握到時兩手**一起握緊一下**（過衝 1.8° 再回正），像一次確認 |
| 媒合者 | 不畫出來，而是那段「縮短距離」的過程本身；媒合者的工作就是讓兩手之間的空隙消失 |
| 社區的溫度 | 握手之後，家（巳）的窗燈才亮起：因為有這次互助，家裡亮了 |
| 長者的身體 | 長者伸手時拐杖杖腳不動，杖頭跟著手微微傾斜，重心是真實的 |

## 時間軸（共用一條 4.2 秒時間軸）

| 秒 | 動作 |
|---|---|
| 0–0.7 | 標準字以「雙手張開」的姿態淡入：巷的手垂下 18°，伴的手收回 7° |
| 0.9 | 長者的手先起步 |
| 1.13 | 青年的手起步 |
| 2.0 | 兩手同時回到原設計位置（握到） |
| 2.0–2.9 | 一起握緊一下，衰減後靜止 |
| 2.3–3.7 | 窗燈暖機亮起，之後靜止 |

## 技術說明
兩隻手從筆畫切下，各自以手腕為軸心旋轉：巷的手軸心在手腕上緣 (651,1108)，伴的手軸心在手腕左緣 (706,929)。切口疊 4–6px，靜止時看不到接縫。拐杖以杖腳 (793,1310) 為軸，角度依握把位移換算。

## 延伸到工具組
兩隻手的兩種姿態可以直接當成工具組的狀態符號：
- **張開**＝待媒合（需求卡、媒合板上還沒配對的狀態）
- **握到＋燈亮**＝這次互助完成（完成貼紙、App 回饋動畫、據點牆上的紀錄）

讓標準字的動態和工具的使用流程講同一件事。
