# 巷伴 動態標準字 v5：雙手伸出（平滑手臂）

打開 `index.html` 播放（純 SVG + CSS）。
預覽檔：`xiangban-light/dark.mp4`、`xiangban-light/dark.gif`（5.6 秒，完整畫面）、`xiangban-hands-closeup.gif`（雙手特寫）。

## 概念：一次媒合，就是兩隻手在同一刻握到

| 專案理念 | 動態轉譯 |
|---|---|
| 長者不只是被照顧，而是還被需要 | **長者的手（伴，握拐杖）先伸出**，比青年早 0.25 秒起步 |
| 青銀雙向 | 青年的手（巷）慢一步回應，但兩隻手**同時抵達**，誰也不是單方面接受 |
| 即時完成的互助 | 握到時兩手**一起握緊一下**（過衝 1.8° 再回正），像一次確認 |
| 媒合者 | 不畫出來，而是那段「縮短距離」的過程本身；媒合者的工作就是讓兩手之間的空隙消失 |
| 社區的溫度 | 握手之後，家（巳）的窗燈才亮起：因為有這次互助，家裡亮了 |
| 長者的身體 | 拐杖完全不動，穩穩立著；長者的手伸下來握住它 |

## 時間軸（約 4.2 秒後靜止）

| 秒 | 動作 |
|---|---|
| 0–0.5 | 標準字淡入。兩條手臂都縮得很短 |
| 0.5 | 長者的手（伴）先伸出：撇由短伸長，手腕沿弧線落到拐杖握把 |
| 0.8 | 青年的手（巷）從屋旁伸出：先往下沉，再往上伸到定位 |
| 2.0 | 兩手同時抵達 |
| 2.0–2.75 | 一起「握一下」：沿手腕方向再伸一點再收回 |
| 2.75–3.05 | 原稿手臂淡入蓋上（與即時手臂幾乎重合，看不出切換） |
| 2.3–3.7 | 窗燈暖機亮起 |

## 技術說明
- **手臂是每一格即時算出來的平滑曲線**：從原字形量出兩條手臂的中心線（三次貝茲曲線，擬合誤差小於 0.3px）和每個斷面的粗細，動畫時依手腕位置與手掌角度重新生成手臂輪廓。沒有硬接點，所以不會有骨頭般的凸角。
- 手掌保持原稿形狀，永遠接在手臂末端，方向跟著曲線切線。
- 肩膀（巷）和撇的頂端（伴）固定，手臂從那裡長出來，起點切線與原稿一致。
- 拐杖（含握把）完全不動。
- 抵達後換回原稿向量，靜止畫面和原本的標準字完全一樣。
- 調整動作：`gen5.py` 裡的 `T`（時間）和 `POSE`（起始位置 P0、手掌角度 ang0、手腕弧線控制點 C、握一下的距離 over）。網址加 `?debug` 會把手臂標成綠色、手掌標成藍色，方便檢查接點。

## 延伸到工具組
兩隻手的兩種姿態可以直接當成工具組的狀態符號：
- **張開**＝待媒合（需求卡、媒合板上還沒配對的狀態）
- **握到＋燈亮**＝這次互助完成（完成貼紙、App 回饋動畫、據點牆上的紀錄）

讓標準字的動態和工具的使用流程講同一件事。
