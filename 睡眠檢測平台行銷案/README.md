# 睡眠呼吸中止症 AI 檢測平台｜行銷企劃專案

學期競賽專案。目標：為一套「雲端 AI 上呼吸道檢測平台」設計行銷文宣，
第一階段說服**醫師族群（B2B）**願意導入並向病患推薦，第二階段再打**消費者（B2C）**。

## 時程

| 日期 | 里程碑 | 要求 |
|---|---|---|
| 9/16 | 參訪公司 | 下午 1:20 集合簽到（已完成） |
| **10/21** | **第一次提報｜醫師族群** | **至少兩種媒材（動態 1＋靜態 1），科別不限** |
| 11/25 | 第二次提報｜消費者（病患）族群 | 至少兩種媒材，依照第一次選定的科別 |
| 12/23 | 第三次提報｜兩客群修正後定稿 + 頒獎 | 第一名 2 萬 / 第二名 1 萬 |

媒材定義（依課堂投影片）：
- 動態：短影音（最少 1 分鐘）、動畫（最少 30 秒）、Podcast
- 靜態：三折頁、DM、說明手冊
- 兩種媒材＝動態與靜態各一種

> 口頭補充另有放寬：「呈現形式不限，可採用平面圖文、影片、2D 動畫或 VR 模式」。
> 投影片是下限，不是上限 —— 見 `03-媒材形式盤點.md`。

## 硬性規範（違反會直接扣分或被主管退件）

1. **文宣上必須清楚標示 TFDA 認證**（第二類醫療器材許可證），這是取得醫師信任的關鍵。
2. **不得揭露具體合約條款與拆帳細節**。簡報重點放在「這套系統如何成為診所擴充業務的工具」。
3. 群組提問格式：`我是第 O 組，提問題目如下：……`，主管會在群組公開回覆，不接受私下回覆。
